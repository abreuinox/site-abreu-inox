## Regras anticanibalização

- Uma intenção comercial = uma página. "Corrimão" vive só em `/solucoes/corrimaos-em-inox/`; artigos linkam para ela, não competem com ela.
- Projetos individuais são otimizados para a aplicação ("guarda-corpo para escada helicoidal em granito") e linkam para a página de solução.
- Não criar páginas por cidade ("corrimão inox Águas Claras", "corrimão inox Taguatinga"). A Vital Inox tentou isso, e as páginas hoje dão 404.
